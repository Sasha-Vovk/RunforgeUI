# React + Typescript + Vitest + Vite

---

## Как запускать

npm install
npm run dev  
npm test # для запуска тестов

## демо

runforgeui.netlify.app

## Структура

src/
├── page/ страницы
├── components/ Sidebar, Filters, List, Drawer, StatusBadge, LoadingSkeleton
├── shared/ общие переменные, функции
├── tests/ Vitest 3 теста
├── server/ Promise + задержка + имитация ошибки, mock данные
├── App.tsx layout (sidebar + main)
├── main.tsx точка входа
└── index.css глобальные стили и CSS-переменные
