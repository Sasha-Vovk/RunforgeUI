# React + Typescript + Vitest + Vite

---

## Как запускать

npm install
npm run dev  
npm test # для запуска тестов

## демо

runforgeui.netlify.app

## Структура

components/ - содержит все компоненты

pages/ - единственное место, где живёт состояние: загрузка, поиск, фильтр и сортировка. Остальные компоненты получают данные через пропсы и сообщают наверх о действиях колбэками.

В shared/ лежит всё переиспользуемое: типы модели, константы, форматтеры дат и длительности, а также useRunsUrlState — хук, который синхронизирует фильтры с query-строкой. Импорты идут через алиас @/shared.

server/ - здесь лежат данные и mock сервис. fetchRuns возвращает Promise с задержкой. Если заменить его на реальный HTTP-клиент, компоненты менять не придётся.

tests/ - содержит тесты
